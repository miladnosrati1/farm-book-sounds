## 📁 ساختار پوشه‌ها و فایل‌ها

```text
├── audio/                  # محل قرارگیری ۹ فایل صوتی MP3 طبیعی و باکیفیت
├── data/
│   └── animals.json        # اطلاعات ۹ حیوان (شناسه، نام فارسی، ایموجی، مسیر فایل صوتی)
├── qr_output/              # خروجی اسکریپت پایتون برای تحویل به صفحهآرا و چاپخانه
│   ├── svg/                # کیوآرکدهای برداری (Vector SVG) مناسب ایندیزاین و ایلستریتور
│   ├── png_300dpi/         # کیوآرکدهای PNG با کیفیت چاپی 300DPI همراه با برچسب نام حیوان در پایین
│   └── manifest.csv        # فایل اکسل راهنما شامل نام حیوان، لینک پلیر، لینک مستقیم MP3 و نام فایل QR
├── scripts/
│   ├── generate_qrs.py     # اسکریپت پایتون برای ساخت فایلهای صوتی نمونه و تولید کیوآرکدها
│   └── fonts/              # فونت وزیرمتن بولد برای رندر دقیق عناوین فارسی روی کیوآرکدها
├── .github/
│   └── workflows/
│       └── deploy.yml      # تنظیمات GitHub Actions برای انتشار خودکار در GitHub Pages
├── index.html              # صفحه وب پلیر کودکپسند و فهرست حیوانات
├── style.css               # استایل شاد، کودکانه، واکنشگرا (Mobile-First) با فونت فارسی وزیرمتن
└── app.js                  # منطق مسیریابی از طریق پارامتر URL (?s=hen) و پخشکننده صوتی
```

## 🎨 ویژگی‌های پلیر وب (Web Player)
1. **طراحی کودکانه و شاد:** استفاده از رنگ‌های جذاب مزرعه، انیمیشن موج‌های صوتی و ترقه‌های شاد در پایان پخش صدا.
2. **پشتیبانی کامل از موبایل (Mobile-First):** کلیدهای لمسی بزرگ و ارگونومیک برای دستان کوچک کودک یا والدین.
3. **پخش خودکار هوشمند (Autoplay):** تلاش برای پخش خودکار به محض اسکن کیوآرکد، همراه با نمایش دکمه بزرگ چشمک‌زن در صورت محدودیت مرورگر تلفن همراه.
4. **مسیریابی با پارامتر URL:** با اضافه کردن `?s=cow` یا هر شناسه دیگر، مستقیم حیوان مدنظر انتخاب و پخش می‌شود.
5. **فهرست کامل حیوانات:** امکان جابه‌جایی سریع و شنیدن صدای سایر حیوانات بدون نیاز به اسکن مجدد.
6. **دانلود مستقیم:** امکان دریافت فایل صوتی به صورت مستقل برای والدین.

## 🖨️ راهنمای چاپخانه و صفحه‌آرا (InDesign / Illustrator)
- برای طراحی صفحات کتاب در نرم‌افزارهای برداری مانند Adobe InDesign و Illustrator، ترجیحاً از فایل‌های وکتور پوشه `qr_output/svg/` استفاده کنید تا کیفیت چاپ در هر ابعادی ۱۰۰٪ حفظ شود.
- برای پیش‌نمایش یا چاپ دیجیتال سریع، فایل‌های پوشه `qr_output/png_300dpi/` از رزولوشن چاپی ۳۰۰DPI برخوردار بوده و دارای برچسب زیبای فارسی با فونت وزیرمتن هستند.
- جدول تطبیق کامل لینک‌ها و فایل‌ها در `qr_output/manifest.csv` قرار دارد.

## 🚀 نحوه اجرای اسکریپت تولید مجدد کیوآرکدها
در صورت تمایل به تغییر دامنه یا اضافه کردن حیوانات جدید:

```bash
# نصب وابستگی‌ها
pip install qrcode[pil] pillow arabic-reshaper python-bidi

# اجرای اسکریپت
python scripts/generate_qrs.py
```
